# Instinct — 原子经验账本

> 主文件：[SKILL.md](../SKILL.md)。只在要写入、提升或淘汰一条经验时读。
>
> **本文件是置信度规则的唯一权威。** 别处只说"参见这里"，不复述数字。

## 一条 instinct 长什么样

```yaml
---
id: desktop-first-for-gui
trigger: 装 GUI 安装包、需要点界面、命令行搞不定交互时
confidence: 0.7
domain: tooling
evidence: 2
first_seen: 2026-11-23
last_seen: 2026-11-23
---
一次失败就换执行上下文，同一条命令不跑第三次。
```

**七个字段全都要写**，少一个就出问题：

| 字段 | 作用 | 漏了会怎样 |
|---|---|---|
| `id` | 脚本认它的唯一依据 | `--check` 报「id 为空」 |
| `trigger` | 什么时候被想起 | `--check` 报缺字段 |
| `confidence` | 多硬 | `--check` 报缺字段 |
| `domain` | 该并入哪个 skill | `--check` 报缺字段 |
| `evidence` | 不是错觉的证明 | `--check` 报缺字段 |
| `first_seen` / `last_seen` | 多久没用了 | `--check` 报缺字段或日期不合法 |

写完跑一次 `--check`，它会逐条告诉你哪里不对。

## 置信度怎么动

| 分数 | 含义 | 行为 |
|---|---|---|
| 0.3 | 试过，不确定 | 只在明确相关时提一句 |
| 0.5 | 有点把握 | 相关时应用 |
| 0.7 | 稳了 | 主动应用 |
| 0.9 | 铁律 | 可提升进 skill 正文 |

**涨：每次复发 +0.1**（同类情况又出现，且没被纠正），`evidence` +1，`last_seen` 更新到今天。

**跌，分三种，看清是哪种再说：**

| 用户说了什么 | 意思 | 动作 |
|---|---|---|
| 「又来了」「我说过了」「你怎么又」 | **上一条没生效** | 置信 **跳到 0.9**，`evidence` +1 |
| 「不对」「不是这样」「不是这个意思」 | **这条经验本身是错的** | 置信 **归 0**，删掉 |
| 沉默但换了个做法 | 参考价值不足 | 置信 −0.1 |

前两种方向相反，区别在**否定的是执行还是内容**：
- 否定执行 → 这条道理对，是我没用上 → 涨到铁律
- 否定内容 → 这条道理错 → 立刻删

**长时间不再出现**：不自动扣分，靠 `--stale 30` 捞出来人工判断。

## 什么时候写

一个任务收尾时，只问一句：**这次有没有一个动作，下次遇到同样情况我想直接照做？**

有 → 写一条，`confidence: 0.5`。
没有 → 不写。**绝大多数任务没有。**

写的是动作，不是上下文：用了什么库、这次的文件路径、跑了多久——这些随着任务结束就失效了。

## 什么时候提升成 skill

**只有一条路**：

```
confidence >= 0.9 且 evidence >= 3
```

这两个数字在 `scripts/instinct.py` 里是常量 `THRESHOLD_CONFIDENCE` / `THRESHOLD_EVIDENCE`，`--ready` 直接读它们。**改门槛就改那两个常量，文档跟着改**——别处给的任何旁路都作废。

同 `domain` 攒了多条但每条都没到门槛，说明它们**还没被验证够**——继续保持记账，等复发把它们顶上去。

提升时改成已有 skill，不新建——按主文件的查重流程找归属。

## 什么时候删

- 置信归 0（用户否定了内容）→ 删
- 已经被某个 skill 正文覆盖 → 删，重复即成本
- 描述的东西本身会变（版本号、价格、路径）→ 删
- `--stale 30` 捞出来、且确认不会再发生 → 删

## 合并：让账本收敛

**两条 `trigger` 重叠、动作又是同一件事时，合成一条。**

保留 `evidence` 多的那条，`last_seen` 取较新的，删掉被并的那条。

**被并条目的 `evidence` 不累加**——那是合并，不是复发。证据只能靠真实复发长出来，否则合并就成了绕过 0.9 门槛的旁路。

判定重叠：把两条 `trigger` 并排读一遍，如果「出现 A」和「出现 B」在实践中总是一起发生，就是一条。

三条以上同域、动作能串成先后顺序的，不是合并——是等它们各自到 0.9 后一起提升成 skill。

## 文件位置

```
<DSH_HOME>/instincts/
  <domain>.md        # 按领域分文件，一个文件多条 instinct
```

按 `domain` 分文件，不按时间。找得到比记得全重要。

要归档已淘汰的条目，自己建个 `_archive/` 挪进去——脚本只扫顶层 `*.md`，不读子目录，所以归档不会算进账本。

**编码：UTF-8，不带 BOM。** 脚本会容忍 BOM（用 `utf-8-sig` 读），但别依赖它——有些工具链不吃这一套。真正的兜底是：条目写坏了脚本会往 stderr 报「缺 id」或「一条都没解析出来」，不再静默跳过。

不确定 `<DSH_HOME>` 指向哪时用 `Test-Path` 试，别猜——工作区和 DSH_HOME 常常不是同一个目录。
