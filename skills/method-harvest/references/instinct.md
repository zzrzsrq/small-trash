# Instinct — 原子经验账本

> 主文件：[SKILL.md](../SKILL.md)。写入、提升或淘汰一条经验时读这里。
> 字段、置信度、门槛、合并与删除规则以本文件为准；别处只给指针。

## 一条 instinct 长什么样

```yaml
---
id: desktop-first-for-gui
trigger: 装 GUI 安装包、需要点界面、命令行搞不定交互时
confidence: 0.7
domain: tooling
evidence: 2
first_seen: 2026-11-23
last_seen: 2026-11-23
---
一次失败就换执行上下文，同一条命令不跑第三次。
```

七个字段写齐，`--check` 按名字逐项核对。

| 字段 | 写什么 | `--check` 的判定 |
|---|---|---|
| `id` | 唯一标识，脚本认它 | 空或重复都报错 |
| `trigger` | 什么时候该被想起 | 缺失报错 |
| `confidence` | 多硬，0–1 之间的小数 | 缺失或越界报错 |
| `domain` | 并入哪个 skill 的归属键 | 缺失报错 |
| `evidence` | 真实复发次数，整数 | 缺失报错 |
| `first_seen` | 首次记录日，`YYYY-MM-DD` | 缺失或格式错报错 |
| `last_seen` | 最近一次复发日，`YYYY-MM-DD`；`--stale` 按它算新旧 | 缺失或格式错报错 |

## 置信度怎么动

按可观察信号分四支，命中哪支走哪支。

| 分数 | 含义 | 行为 |
|---|---|---|
| 0.3 | 试过，不确定 | 明确相关时提一句 |
| 0.5 | 有点把握 | 相关时应用 |
| 0.7 | 稳了 | 主动应用 |
| 0.9 | 铁律 | 主动应用；再满足 `evidence` 门槛即可提升 |

| 可观察信号 | 落在哪儿 | 动作 |
|---|---|---|
| 同类情况再次出现、用户未纠正 | 复发 | `confidence` +0.1，`evidence` +1，`last_seen` 设当天 |
| 「又来了」「我说过了」「你怎么又」 | 执行：道理成立，只是没用上 | `confidence` 跳到 0.9，`evidence` +1 |
| 「不对」「不是这样」「不是这个意思」 | 内容：经验本身有误 | `confidence` 归 0，删掉 |
| 用户没纠正，但换了做法 | 参考价值低 | `confidence` −0.1 |

久未复发：`confidence` 保持原值，用 `--stale 30` 捞出后逐条判断去留。

## 什么时候写

任务收尾只问一句：**这次有没有一个动作，下次遇到同样情况我想直接照做？**

有 → 写一条，`confidence: 0.5`。
没有 → 不写。

只写动作：下次同类情况能直接照做的那一步。库名、路径、耗时属于当次上下文，随任务结束失效。

## 什么时候提升成 skill

```
confidence >= 0.9 且 evidence >= 3
```

两个数字对应 `scripts/instinct.py` 的 `THRESHOLD_CONFIDENCE` / `THRESHOLD_EVIDENCE`，`--ready` 直接读它们。改门槛先改常量，再同步这里。

同域多条都未到门槛：继续记账，靠复发推进。

提升时并入已有 skill，归属走主文件的查重流程。

## 什么时候删

- `confidence` 归 0（用户否定了内容）
- 已被 skill 正文覆盖
- 描述对象会变（版本号、价格、路径）
- `--stale 30` 捞出且确认不会再发生

## 合并

两个 `trigger` 在实践中总一起出现、动作又相同 → 合成一条：保留 `evidence` 高的那条，`last_seen` 取较新的。

`evidence` 沿用保留条目的原值；它只在真实复发时 +1。

三条以上同域、动作能串成顺序的，各自记账，到门槛后一起提升。

## 文件位置

```
<DSH_HOME>/instincts/
  <domain>.md        # 一个文件多条 instinct
```

按 `domain` 分文件；新旧由 `last_seen` 决定。找得到比记得全重要。

归档：建 `_archive/` 挪进去。脚本只扫顶层 `*.md`，子目录不计入账本。

UTF-8 无 BOM。脚本会剥掉 BOM 再按 UTF-8 读；无 BOM 时先试 UTF-8，再试 GB18030 并告警，都失败就跳过并报「编码认不出来」。写坏的条目会在 `--check` 里报缺字段或坏日期。

路径解析优先级、其余 CLI 参数见 `instinct.py --help`。
