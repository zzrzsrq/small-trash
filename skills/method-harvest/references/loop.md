# 自进化闭环

> 主文件：[SKILL.md](../SKILL.md)。这是整个沉淀系统的运转图——什么时候产生、什么时候淘汰。
>
> 本文件只管**流程与时机**。置信度数字、提升门槛、删除判据一律在 [instinct.md](instinct.md)，不在这里复述。

## 一圈长什么样

```
        ┌─────────────────────────────────────────┐
        │  干活                                    │
        └───────────────┬─────────────────────────┘
                        │
              ┌─────────▼─────────┐
              │ 出了岔子 / 找到好路 │
              └─────────┬─────────┘
                        │  写一条
              ┌─────────▼─────────┐
              │   instinct 账本    │◄──── 复发：涨
              └─────────┬─────────┘◄──── 否定内容：删
                        │
           ┌────────────┴────────────┐
           │                         │
       够门槛                    掉光
           │                         │
     ┌─────▼──────┐             ┌────────┐
     │ 并入 skill  │             │  删掉   │
     └─────┬──────┘             └────────┘
           │
     ┌─────▼──────────────┐
     │ 下次自动生效，省一步 │
     └────────────────────┘
```

门槛数值、涨跌规则全在 [instinct.md](instinct.md)，图上不标数字。

## 三个入口

**① 任务收尾**（最常用）
干完一个非平凡任务，按 [instinct.md](instinct.md) 的「什么时候写」过一遍。
**绝大多数任务到此为止。**

**② 用户不满**
用户的话分两类，动作相反——否定执行，还是否定内容。判据与处理在 [instinct.md](instinct.md#置信度怎么动)。

**③ 用户点名**
「记住这个」「以后别再」「沉淀一下」——立刻记，不问。

## 什么时候不动

- 一次性任务，没有下次
- 已经写进 skill 正文了，重复即成本
- 用户在同一个提议上刚拒绝过

## 账本健康

`--ready` 长期列着却不提升的：回头检查这些条目本身的 `trigger` 是不是写得太泛，或者动作是不是根本没法执行。

提升门槛本身不动——它是验证强度的底线，松一次就再也紧不回来。

**账本价值 = 用过的条数 ÷ 总条数。**
