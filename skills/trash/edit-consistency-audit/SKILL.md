# 改完自查：消灭「删了还在写」

改文档最容易犯的错不是写错字，是**改了一半**：删掉 A，正文别处还在推荐 A。这类错读全文找不出来，只能反查。

## 核心判断：两种提及，只留一种

同一个词在文中出现，要分两种，判错了就是白改：

- **守则式提及**（留）：`本机没有 qpdf，不要用它`——它在防呆，删掉反而害人。
- **推荐式提及**（改或删）：示例代码、速查表、操作步骤里让人去用已删/不存在的东西——这就是 bug。

判据：这句话是在阻止别人用它，还是在教别人用它？前者留，后者改。

## 步骤

1. **先登记，再动手**。改之前把这次要删／改名／改值的 token 列出来：文件名、命令名、库名、路径、数字、标题。没有这张表，就没有反查的依据。
2. **反查残留**。对每个 token 全文搜索，逐条判「守则式 / 推荐式」。
3. **依赖真跑**。路径 `Test-Path`、命令 `--help`、库 `import` 一次。文档里写「实测可用」「已装」「已存在」的，必须真跑过；跑不了就改成「未验证」。
4. **同义名归一**。同一件事出现两个名字（`read-file` 与 `download`、`node` 与绝对路径）就是坑，统一成一个，另一个只允许出现在「不要用」的守则句里。
5. **数字唯一**。同一指标在文中出现多次必须同值（0.3s 不能一处 0.4s；16s 不能另一处 30s）。
6. **规则互斥**。搜「必须 / 禁止 / 不要 / 一律」的句子，找互相打架的两句（「每次都跑」对「不要跑」、「推荐 A」对「A 已删」）。
7. **结构过一遍**。frontmatter 完好、代码围栏成对（``` 计数为偶数）、标题层级不跳级。
8. **交付形态唯一**。全文只能有一种交付形态：单文件 / 多文件目录 / 纯文本。任何步骤要求另一种形态的中间产物，就是矛盾——「交付单文件 `index.html`」却让人把图下载到 `images/` 用相对路径引用，交付出去图片全空。

## 扫描片段

```powershell
# $tokens 换成第 1 步登记的名字
$tokens = 'qpdf','pdfimages','read-file','node scripts'
Get-ChildItem -Recurse -Filter *.md | ForEach-Object {
  $hit = Select-String -Path $_.FullName -Pattern ($tokens -join '|') -ErrorAction SilentlyContinue
  if ($hit) { $hit | ForEach-Object { "{0}:{1}  {2}" -f $_.Filename, $_.LineNumber, $_.Line.Trim() } }
}
```

围栏成对检查（应输出 True）：

````powershell
$c = Get-Content <文件> -Raw
([regex]::Matches($c,'```').Count % 2) -eq 0
````

## 判据（全中才算完）

- 每个被删 token 的残留都判定过，推荐式的全改掉
- 每个「可用 / 已装 / 存在」的断言都真跑过，或明确标为「未验证」
- 没有两个名字指同一件事，没有同一指标两个数
- 没有互相打架的必须／禁止条款
- 围栏成对、frontmatter 完整

## 停手条件

**两轮就停**：残留扫描 + 依赖实跑都干净即结束。为了「再看看」重读全文找不到这类错，只有按 token 反查能找到。第二轮还翻出同类错误，说明第 1 步的 token 表漏了，补表再查一轮。

## 这一课的真实来源

一次批量改 PDF 技能时踩到的六种：

1. 删了「JavaScript 库」整章，正文还写「JS 用法见 REFERENCE.md」
2. 删了命令行章节，示例段还留着 `pdfimages -j`
3. 库清单改成「pypdf 未装」，速查表仍推荐 pypdf
4. 加了「node 不在 PATH」，正文 5 处仍是 `node scripts/...`
5. 写了「一律不带 --skill-updated」，下面示例就带着它
6. 一边规定「交付单文件 index.html」，一边教「图片下载到 images/ 用相对路径」——离线打开图片全空

第 6 种最容易漏：两句话单看都对，合起来交付出来的东西是坏的。六种全是反查抓到的，通读找不出一种。

## 报告格式

三行：

- 删／改了什么：一句话
- 抓到几处：数字 + 分类（断链 / 同义名 / 数字不一致 / 规则互斥）
- 每处一行：行号 + 问题 + 已改成什么
